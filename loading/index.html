煎药中

加载动效原型。一根脉搏线由起伏到平稳，写成一张素笺上的三行字；写完淡去，周而复始。完成时盖一枚朱砂印。

// 挂载；opts 可省，字段见 README
const brew = LoadingBrew.mount(el, opts)
// 开始循环
brew.start()
// 第二行文案；后两个数可省，省略时不显示进度
brew.setStep('正在拟写 责任分工', 3, 5)
// 写完这一遍后停住、盖印；印落定后 resolve
await brew.done()
// 回到开始前，之后再 start()
brew.reset()
// 卸载时调用
brew.destroy()
