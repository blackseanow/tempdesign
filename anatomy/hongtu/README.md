# 宏图解剖图（anatomy/hongtu）

宏图：领导描绘的宏伟蓝图，一层层掀开，看看哪几层是画清楚了的。

一张老式绘图桌：铸铁架子，木面板宽 90 厘米、倾斜 15 度，左边缘夹着一盏摇臂台灯。面板右半边用四枚黄铜图钉钉着 6 张半透明描图纸，叠在一起看是一整张宏图：远山、山顶的旗、盘山路、路边的小旗、人和钱、一把时间尺。每张纸的右边伸出一个纸舌，穿绳挂一块小牌，正面写名字。鼠标悬停（手机上点按），图钉先拔出来，六张纸从上到下依次竖直抬起分开，台灯的灯头跟着转，灯光照亮刚抬起的那一层，小牌翻过来露出领导的原话。按 [anatomy 技能](../../.claude/skills/anatomy/SKILL.md) 的流程和 kit 制作，浅色主题换成了平台的设计系统。

## 物件和数字

从上到下六层。清晰度不是写死的标签，而是量出来的：一张纸上墨线的总长 ÷ 全部笔画（墨线 + 铅笔线 + 虚线的空档）的总长。`build.mjs` 每次生成都把 `art.mjs` 量出的比例和 `model.mjs` 里的数对一遍，差 0.05% 以上就报错。

| 层 | 名字 | 小牌背面 | 纸上画了什么 | 清晰度 | 权重 |
|---|---|---|---|---:|---:|
| 1 | 愿景 | 要有大格局 | 远处的三座山，山脊、雪线、阴影排线全是墨线 | 100% | 1 |
| 2 | 目标 | 三年翻一番 | 主峰顶上一面旗，旗面和两道向上的折线是墨线，旗杆下面那一截只是铅笔线，插不到山顶上 | 80% | 2 |
| 3 | 路线图 | 路径大家再想想 | 从山脚盘到山顶的路，只画了前一半，而且是虚线（墨 4、空 6）；后一半只有铅笔点 | 20% | 3 |
| 4 | 里程碑 | 节点倒排 | 五面小旗，全挤在路的半中间；一面画全，一面只有旗杆，其余都是铅笔 | 30% | 2 |
| 5 | 资源 | 人手先克服一下 | 三个人、一个钱袋、一摞硬币，只有铅笔轮廓 | 0% | 3 |
| 6 | 时间表 | 越快越好 | 底部一把 36 个月的刻度尺，终点用墨线重重圈了三圈 | 100% | 1 |

清晰度 100% 的才算“画清楚”：六层里只有愿景和时间表两层。可执行度是各层清晰度按权重的加权平均，越接近“怎么干”的层权重越高（路线图、资源各 3，目标、里程碑各 2，愿景、时间表各 1，合计 12）：(100 + 160 + 60 + 60 + 0 + 100) ÷ 12 = 40%。

全图唯一的朱砂红在时间表那一层上：尺子终点上方一枚“已明确”的长方形橡皮章。整张宏图里，只有截止时间是清清楚楚的。

## 读数

卡片右下角的读数一直是 `范围：画清楚 a/n 层 · 可执行度 x%`，和图纸的位置来自同一时刻的同一份状态：

- 合拢：`整张宏图：画清楚 2/6 层 · 可执行度 40%`。
- 抬起时改成“已掀开 n 层”，只算已经离开纸堆（抬起超过 2 毫米）的那几层：依次是 1/1 · 100%、1/2 · 86.7%、1/3 · 53.3%、1/4 · 47.5%、1/5 · 34.5%。越往下看越不清楚。
- 最后抬起时间表：`六层都掀开：画清楚 2/6 层 · 可执行度 40%`。截止时间那一层把分数又拉回了一点。
- 合上时倒过来，时间表最先落回，读数一层层减回去，第 1 层落回后又是“整张宏图”。

手机上读数分两行：范围一行，数字一行。

## 动效

| 动作 | 参数 |
|---|---|
| 触发 | 鼠标或触控笔移进卡片就拆开，移出就合上；触屏点按切换；键盘：空格或回车切换，↑ 拆开，↓ 或 Esc 合上 |
| 依次 | 七组弹簧：四枚图钉一组最先走，然后六张纸从上往下，每组晚 0.46 秒；合上时倒过来，最后抬起的最先落回。中途反悔只重排还没出发的组，已经出发的立刻往回走（和 kit 审计重放的规则一致） |
| 抬起 | 弹簧刚度 30、阻尼 11（临界阻尼，不过冲，落回时不会压进下一层），每帧 4 个子步。纸保持和桌面平行，竖直向上：第 1 层抬 360 毫米，往下每层少 60 毫米，时间表抬 60 毫米 |
| 图钉 | 沿“竖直 360 毫米 + 钉子方向 40 毫米”的合成方向出来，停在第 1 层钉孔正上方 40 毫米处，针尖对着孔；针原本插在纸堆和面板里，离开纸堆时才淡入 |
| 灯 | 灯头绕关节转，对准“抬到八成以上的最下面那一张”的中心（还没有时对准第 1 张），临界阻尼跟随，时间常数 0.18 秒：先随第 1 张抬到 −26°，再一层层往下扫，停在时间表上（−47°）；合上时倒过来。抬到 −42° 以上时灯罩口转向观者，看得见里面的白珐琅。被照的那张纸上落一片暖白的光（纸面受光变白，中心偏暖），纸边变成墨色，其它层的画退到 72%。光只落在纸面上，空中不画光束，也没有发光、光晕 |
| 小牌翻面 | 和它那层同时开始，绕绳子转 180°，弹簧刚度 22、阻尼 9.4；牌面明暗随朝向连续变化，接近侧对时文字淡出 |
| 读数 | 和图纸位置来自同一时刻的同一份状态，一层离开或落回纸堆时更新 |
| 减少动态效果 | 只显示拆开后的静态画面：六层都抬起、小牌全翻好、灯照着时间表、读数是六层的总账，不响应悬停和点按；运行中切换系统设置会跟着变 |
| 滚出视口 | 停止动画（IntersectionObserver），回来接着走 |

## 尺寸、镜头和颜色

世界单位是毫米，方位角 60°，仰角 38°（看纸面更正一些），viewBox `600 × 798`，0.518 px/mm。面板 900 × 600 × 28 毫米，前缘高 600 毫米，绕 x 轴斜 15°，两端是横纹木条；描图纸 520 × 540 毫米，叠放时每张 0.5 毫米；小牌 40 × 84 毫米。铸铁架两根升降立柱（外套管、锁紧环和旋钮、内管），顶上是转轴和带刻度的倾角扇板，脚下有调平脚、横撑和脚踏。台灯夹在面板左缘：夹钳、斜口插座（铸成 15°，灯杆因此竖直）、转座、两节各 358 毫米的双杆灯臂、两根拉簧、肘关节和灯头的锁紧旋钮、灯罩上的通风孔和按钮开关。灯臂所在的竖直平面正好穿过图纸中心抬升的那条竖线，灯头只绕一根轴转就能对准每一层。面板左边放着三角板、三棱比例尺、圆规和橡皮，笔槽上两支铅笔，笔槽正面一块黄铜铭牌。

| 色名 | 值 | 用在 |
|---|---|---|
| 竹纸 | `#ECEAE1` | 页面底色，描图纸的纸色（20% 透明度） |
| 素笺 | `#F8F7F2` | 卡片、小牌、灯罩里的白珐琅 |
| 松烟墨 | `#24231F` | 线条、文字、纸上的墨线 |
| 古铜金 | `#C9A86A` | 木面板、黄铜件（图钉、旋钮、弹簧、铭牌）的四档明暗：`#E2CB98`、`#D6BB83`、`#C9A86A`、`#B7955A` |
| 函套青 | `#1F3A4D` | 铸铁架子和台灯，同一色系由浅到深：`#5D798D` … `#1F3A4D` |
| 朱砂 | `#B5382A` | 只用在时间表那一层的“已明确”章 |
| 浅调和灰调 | | 灯光是古铜金调的暖白（`#FFF1CC` 渐隐到透明），只落在纸面上；铅笔线是松烟墨的灰调 `#9A958A`；三角板是函套青的浅调，比例尺、橡皮是素笺一路的象牙色，圆规和图钉的针是钢灰 |

没有发光，只有两只脚下面一层柔和的投影。所有文字是中文，字体栈 `"LXGW WenKai","Hongtu WenKai","KaiTi","STKaiti",serif`：先用 CDN 的霞鹜文楷；取不到时用内嵌的子集 “Hongtu WenKai”（来自 `lxgw-wenkai-webfont@1.7.0` 的 Regular，只做了子集化，SIL OFL 1.1，许可证见 `fonts/OFL.txt`）；再退到楷体。

## 自查

- `node build.mjs --audit`：audit passed，输出在 `screenshots/checks/audit.txt`。间隙、端点、松端、折线、支撑和嵌入、深度顺序（1943 个状态，含弹簧回放、每个交错边界前后 8 毫秒的反悔和前缀状态）、回放中的穿插（7702 帧）、自交、坡度、鞍座、替身形状、拥挤全部为 0。两处和 kit 默认做法不同，都写在 `build.mjs` 里：
  - 六张纸之间、纸和面板以下的零件之间不做光线求交：纸是平行薄片，只会竖直往上分开，上面的永远盖住下面的，键值本身就保证这个顺序（这样解深度顺序从 9 分钟降到 30 秒）。
  - 实体穿插在静止、分开和前缀状态（kit 认定的最坏帧）按 1.2 毫米取样，回放帧每 4 帧按 3 毫米取样，并且不查“纸 × 纸”“纸 × 面板以下”这两类不可能相遇的对；kit 默认的 0.6 毫米逐帧取样对 0.28 平方米的纸面要跑几个小时。管线（小牌的绳子）照 kit 的做法逐帧检查。
- 技能的 `scripts/lines.mjs`：合拢和拆开两种姿态都是 `line ends: 0 of 3062 ends on 70 lines float`。纸上画的东西（墨线、铅笔线、虚线）是图纸的内容，不是机件的线，不进这项检查。
- 清晰度：每次生成都把 `art.mjs` 量出的墨线比例和 `model.mjs` 对一遍：100.00 / 80.00 / 20.00 / 30.00 / 0.00 / 100.00。
- 技能的 `scripts/capture.mjs`、`scripts/drive.mjs`：桌面 1440、手机 390 宽、减少动态效果、拆开和合上的连拍（读数一层层变化：40% → 100% → 86.7% → 53.3% → 47.5% → 34.5% → 40%，合上时倒过来），以及每处接缝（夹钳和插座、灯臂的眼和杆、拉簧和横销、灯头关节、笔槽和铭牌、立柱和横撑、纸舌和绳子）和每块小牌正反面的 4–8 倍特写，每张都看过。控制台无报错，页面不横向滚动。独立 SVG 按 XML 校验，用 `<img>` 引用也能显示内嵌字体。

## 重建

```sh
node build.mjs            # 写 hongtu.html 和 hongtu.svg（约 30 秒，大部分时间在解深度顺序）
node build.mjs --draft    # 草稿：只用均匀和前缀状态解深度顺序
node build.mjs --quick    # 草稿：不解深度顺序
node build.mjs --audit    # 同时跑审计（约 9 分钟）
```

改了文字以后重做字体子集：`node build.mjs --chars`，再 `python3 tools/subset.py --package <解开的 lxgw-wenkai-webfont 包目录>`（需要 fontTools 和 brotli）。截图脚本需要 Chrome 或 Chromium：设 `CHROME_PATH`，或者 `npx playwright install chromium`。

```sh
CHROME_PATH=/path/to/chromium node ../../.claude/skills/anatomy/scripts/capture.mjs hongtu.html --out shots/closed.png
CHROME_PATH=/path/to/chromium node ../../.claude/skills/anatomy/scripts/lines.mjs hongtu.html --out shots/lines.png
```
