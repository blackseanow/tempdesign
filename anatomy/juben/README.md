# 剧本解剖图（anatomy/juben）

剧本：会议早有剧本，开场、回顾、表态都按部就班；一幕幕拉开，看看两个小时里，真正要记下来的是哪一幕。

一个木制翻页架，高 120 厘米，三条腿撑开，架上夹着一本线装剧本：函套青的布面，右边四眼订线，订线两头包着角，左上角一张题签写着“剧本”，封面正中一张古铜金的京剧脸谱。剧本里是五幕纸雕立体舞台，像一本隧道式立体书，从前往后依次是开场、回顾、问题、要求、表态；每幕是一排地景纸雕、一道函套青的幕布和一张纸雕拱门。每幕拱门的左边伸出一个纸舌，穿绳挂一块小牌，正面写名字。鼠标悬停（手机上点按），封面绕着订线旁的折痕翻开，五幕舞台依次弹出、错开排开，幕布一幕幕向两边拉开，小牌翻过来露出领导的原话。按 [anatomy 技能](../../.claude/skills/anatomy/SKILL.md) 的流程和 kit 制作，浅色主题换成了平台的设计系统。

## 五幕和数字

从前往后五幕，时长写在 `model.mjs` 里，读数、图例、说明和封面里面的戏单都从这里算。只有“要求”一幕标着要记。

| 幕 | 名字 | 小牌背面 | 舞台上 | 时长 |
|---|---|---|---|---:|
| 1 | 开场 | 今天就简单说几句 | 铺着台布的主席台，一排六只话筒，一只青花盖碗 | 20 分钟 |
| 2 | 回顾 | 成绩是主要的 | 一面玻璃展柜，四层摆满奖杯，还挂着一枚奖章 | 45 分钟 |
| 3 | 问题 | 主要是执行不到位 | 一面落地穿衣镜，镜面朝着台下 | 35 分钟 |
| 4 | 要求 | 下面我强调几点 | 一块写满九条的告示板，下半截斜盖着一枚“划重点” | 5 分钟 |
| 5 | 表态 | 大家没意见，就这么定了 | 台下一排椅背，后面竖起七块打了勾的表决牌 | 15 分钟 |

合计 120 分钟，两个小时。要记的只有要求那 5 分钟，占 4.2%。

全图唯一的朱砂红在第四幕的告示板上：一枚斜盖的长方印“划重点”。两个小时的戏，真正要记下来的只有这五分钟。

## 读数

卡片右下角的读数是 `已拉开 n/5 幕 · 累计 t 分钟 · 要记的占比 p`，和幕布的位置来自同一时刻的同一份状态：一道幕布拉开过一半，这一幕才算上演，它的时长才计入。

- 合拢：`已拉开 0/5 幕 · 累计 0 分钟 · 要记的占比 —`（还没有时长，占比无从算起）。
- 拉开时依次是 1/5 · 20 分钟 · 0%、2/5 · 65 分钟 · 0%、3/5 · 100 分钟 · 0%、4/5 · 105 分钟 · 4.8%、5/5 · 120 分钟 · 4.2%：前一百分钟里要记的一分钟也没有，第四幕拉开才有。
- 合上时倒过来，最后拉开的幕布最先合上，读数一幕幕减回去。

手机上读数分两行：幕数和累计一行，占比一行。

## 动效

| 动作 | 参数 |
|---|---|
| 触发 | 鼠标或触控笔移进卡片就拆开，移出就合上；触屏点按切换；键盘：空格或回车切换，↑ 拆开，↓ 或 Esc 合上 |
| 依次 | 一条交错表，每拍 0.18 秒：封面先翻，空三拍，五幕从前往后每拍弹出一幕；五幕都出来以后，幕布每两拍拉开一道。合上时倒过来：幕布从最后一道开始合，再一幕幕收回，第一幕开始收回以后再空三拍封面才合上，这时它已经差不多到家，封面的板边绕着折痕转过去，碰不到它的拱门。中途反悔只重排还没出发的，已经出发的立刻往回走（和 kit 审计重放的规则一致） |
| 弹簧 | 刚度 26、阻尼 10.2（临界阻尼，不过冲，收回时不会撞进后一幕），每帧 4 个子步。封面、五幕、幕布、空拍用同一组弹簧 |
| 封面 | 绕订线旁的折痕翻开 168°，从挡在书页前面，转到书的右边，露出里面的戏单；布面的明暗随朝向连续变化。它在画家顺序里的位置跟着角度走：生成时在 15 个角度上量好它和每个零件的前后；翻到 120.2° 板面正好侧对读者，此前读者看到的是外面，五幕都在它后面，所以它还要压在五幕当时的位置上面，哪怕某一幕还没完全收回；此后看到的是里面，五幕在它前面 |
| 五幕 | 每幕沿书页的法线弹出，第一幕最远（500 毫米），往后每幕少 100 毫米；越靠前的一幕往右挪得越多，正好抵掉从右前方看过去的视差，五道拱门在画面上排成一条隧道。拱门比自己的地景多出来 38 毫米，幕布在两者之间，每幕自成一个小舞台 |
| 幕布 | 每半幅 7 个褶，布比幅宽多 6%，合上时是浅褶；拉开时收到两边，幅宽收窄 84%，布长不变，褶就变深；每一帧按褶的朝向重新分四档明暗 |
| 小牌翻面 | 和它那一幕的幕布同时开始，绕绳子转 180°，弹簧刚度 22、阻尼 9.4；牌面明暗随朝向连续变化，接近侧对时文字淡出 |
| 读数 | 和幕布来自同一时刻的同一份状态，一道幕布拉开过一半时更新 |
| 减少动态效果 | 只显示拆开后的静态画面：封面翻开、五幕排开、幕布全拉开、小牌全翻好、读数是五幕的总账，不响应悬停和点按；运行中切换系统设置会跟着变 |
| 滚出视口 | 停止动画（IntersectionObserver），回来接着走 |

## 尺寸、镜头和颜色

世界单位是毫米，方位角 57°，仰角 28°，viewBox `600 × 784`，0.586 px/mm。

翻页架：两条圆木前腿从地面撑到顶梁，下端是黄铜箍和橡胶脚，前脚间距 672 毫米；后腿铰在顶梁背后，脚落在前脚后面约 790 毫米处；两条前腿之间一根横撑，横撑中间套一个铜箍，一条两节的黄铜撑杆折到后腿上的铜箍，定住三条腿张开的角度。木板向后斜 13°，下边是托盘（下面两块三角托架，正面一块铜铭牌，槽里放着一根教鞭），上边是压条，两颗滚花铜螺丝压住剧本的背板。顶梁上两颗铜螺栓穿着两条前腿，顶梁上沿离地 1203 毫米。

剧本：背板 460 × 592 毫米，比书页高出一截，上沿夹在压条里；五幕各占 9 毫米一格，封面 432 × 570 × 5 毫米，合起来 56 毫米厚。右边是订线的书脑，四个订眼，线顺着订线走，在每个眼上绕过书脊，两头各包一块角。封面外面是题签“剧本”和脸谱，里面贴着衬纸，印着一张戏单：五行，每行一条横条，长短按这一幕的时长画，要求那一条只有一小截。

每幕：纸雕拱门 402 × 530 毫米，右边离折痕留出 24 毫米（封面的板厚 5 毫米，绕折痕转的时候板边会扫进书页一侧，弹出的一幕又会往订线那边错开），两根柱子各 26 毫米，横楣下面一排九个垂花，柱子上有柱础、两道凹槽和柱头，横楣上一排菱纹，正中一枚小圆章，点数就是第几幕；左边伸出 76 毫米的纸舌，穿一根绳挂 40 × 88 毫米的小牌，越往后的一幕纸舌越高，合着的时候五块牌在书的左边排成一列。地景是一条 60 毫米高的台口，上面立着这一幕的纸雕。

| 色名 | 值 | 用在 |
|---|---|---|
| 竹纸 | `#ECEAE1` | 页面底色 |
| 素笺 | `#F8F7F2` | 卡片、小牌、纸雕、衬纸 |
| 松烟墨 | `#24231F` | 线条、文字 |
| 古铜金 | `#C9A86A` | 翻页架的木头、拱门、铜件、脸谱、奖杯，四档明暗：`#E2CB98`、`#D6BB83`、`#C9A86A`、`#B7955A` |
| 函套青 | `#1F3A4D` | 剧本的布面、五道幕布、话筒、告示板的抬头，四档明暗：`#5D798D`、`#4B677B`、`#3B576C`、`#2D485C`，最深是 `#1F3A4D` |

没有发光，没有人物：脸谱画成三块瓦的图案，眼睛只是两道细缝；第五幕的“台下”只有椅背和举起的牌子。所有文字是中文，字体栈 `"LXGW WenKai","Juben WenKai","KaiTi","STKaiti",serif`：先用 CDN 的霞鹜文楷；取不到时用内嵌的子集 “Juben WenKai”（来自 `lxgw-wenkai-webfont@1.7.0` 的 Regular，只做了子集化，SIL OFL 1.1，许可证见 `fonts/OFL.txt`）；再退到楷体。

## 自查

- `node build.mjs --audit`：audit passed，输出在 `screenshots/checks/audit.txt`。间隙、端点、松端、折线、支撑和嵌入、深度顺序（1895 个状态，含弹簧回放、每个交错边界前后 8 毫秒的反悔和前缀状态）、回放中的穿插（7486 帧）、自交、坡度、鞍座、替身形状、拥挤全部为 0。和 kit 默认做法不同的地方都写在 `build.mjs` 里：
  - 封面是转的，不是平移的，kit 的回放不管它，另做了三项。五幕的纸卡和封面的板都是顺着折痕的薄片，所以在全部 7486 个回放帧里，按当时的角度和位置，在垂直于折痕的截面上精确地算两者的距离：最近 0.01 毫米，是封面合上那一刻贴到第一幕拱门上。封面对固定零件，每半度一个角度（337 个），用板面上每 4 毫米一个的点去量。它在画家顺序里的位置（页面和审计用同一个 `coverKeyOf`）每 8 个回放帧拿真实深度对一次，483 帧都对。
  - 一幕里的地景、幕布、拱门三张纸卡一起走，彼此之间不解深度顺序，键值本身保证从后往前；重叠按 1 个单位的网格量。解深度顺序从十几分钟降到 6 分钟。
  - 实体穿插在静止、分开和前缀状态（kit 认定的最坏帧）按 1.2 毫米取样；回放帧每 4 帧按 3 毫米取样，只查自静止以来相对位置变了的零件对。每一对只在两者在画板坐标里的外框相距不到半毫米时才取样。小牌的绳子照 kit 的做法逐帧检查。
- 这次自查找到并修好的问题：
  - 合上时封面开始往回转，第一幕还在外面约四分之一（只错开 0.54 秒）。封面靠折痕的板边扫过第一幕拱门的右柱，最深穿进 16 毫米；页面里封面的键值又只比第一幕静止时高 0.01，第一幕没完全收回就画到了封面上面。改成：拱门右边离折痕留 24 毫米（宽 422 → 402 毫米），封面和第一幕之间多空一拍，封面的画家顺序跟着角度和五幕的实时位置走。
  - 撑杆的铜箍和横撑上的铜夹原来整圈套在杆子上，后腿上那个还横着穿过腿，深度顺序成了环。改成把杆子在铜箍处截成两段，铜箍夹在中间。
  - 包角原来是一个盒子减去书脑，书脑圆角里留下一点料，又伸进背板 1 毫米。改成贴在书脑外面的一块角铁形布片，上头再加一块盖。
  - 小牌的绳子原来贴着纸舌往下走，只隔 0.05 毫米，起点也不在纸舌上。改成从孔里垂直穿出，在纸舌前面 2.5 毫米处绕下来。
- 技能的 `scripts/lines.mjs`：合拢和拆开两种姿态都是 `line ends: 0 of 72 ends on 32 lines float`。纸上印的东西（台布的褶、奖杯、告示板的条目、拱门的菱纹、脸谱的勾线、戏单）另做了一份把它们当线来查的测试页：合拢 `0 of 526`，拆开 `0 of 520`。
- 技能的 `scripts/capture.mjs`、`scripts/drive.mjs`：桌面 1440 宽、手机 390 宽、减少动态效果、拆开和合上的连拍、封面翻开和合上的慢放（0.12–0.15 倍速）、第一幕弹出时折痕一带的慢放，以及每处接缝的特写，每张都看过。读数逐次记录：拆开时 0/5 → 1/5 · 20 分钟 · 0% → 2/5 · 65 · 0% → 3/5 · 100 · 0% → 4/5 · 105 · 4.8% → 5/5 · 120 · 4.2%，合上时倒过来，中途反悔是 0/5 → 1/5 → 0/5。控制台无报错，页面不横向滚动。独立 SVG 按 XML 校验过，用 `<img>` 引用也能显示内嵌字体。

## 重建

```sh
node build.mjs            # 写 juben.html 和 juben.svg（约 7 分钟，大部分时间在解深度顺序）
node build.mjs --quick    # 草稿：不解深度顺序，封面直接压在最上面
node build.mjs --audit    # 同时跑审计（再约一小时十分钟，大部分时间在支撑检查和封面的深度顺序）
```

改了文字以后重做字体子集：`node build.mjs --chars`，再 `python3 tools/subset.py --package <解开的 lxgw-wenkai-webfont 包目录>`（需要 fontTools 和 brotli）。截图脚本需要 Chrome 或 Chromium：设 `CHROME_PATH`，或者 `npx playwright install chromium`。

```sh
CHROME_PATH=/path/to/chromium node ../../.claude/skills/anatomy/scripts/capture.mjs juben.html --out shots/closed.png
CHROME_PATH=/path/to/chromium node ../../.claude/skills/anatomy/scripts/lines.mjs juben.html --out shots/lines.png
```
