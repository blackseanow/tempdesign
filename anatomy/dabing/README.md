# 大饼解剖图（anatomy/dabing）

画大饼：领导许诺的大饼，拆开、称一称，看看里面到底有几层是实的。

一张七层的芝麻千层大饼放在函套青的高脚圆盘里，圆盘放在一台带圆表盘的老式台秤上。每层边缘插一根竹签，挂一块小木牌，正面写名字。鼠标悬停（手机上点按），七层饼从上到下依次抬起分开，木牌翻过来露出领导的原话；每抬起一层，指针就减去这一层的实际分量。按 [anatomy 技能](../../.claude/skills/anatomy/SKILL.md) 的流程和 kit 制作，浅色主题换成了平台的设计系统。

| 文件 | 说明 |
|---|---|
| `dabing.html` | 独立页面：kit、动效脚本、样式和字体子集都内联，只从 CDN 取霞鹜文楷（取不到时用内嵌子集） |
| `dabing.svg` | 独立 SVG：合拢状态的整张图，样式和字体子集都在文件里，可以直接打开，也可以 `<img>` 引用 |
| `screenshots/closed.png`、`screenshots/open.png` | 合拢、分开两种状态的卡片预览，浅色，桌面 1440 宽，2 倍像素 |
| `screenshots/checks/` | 自查截图和审计记录，见“自查” |
| `build.mjs` | 几何、画家顺序、审计、页面和 SVG 的生成脚本 |
| `model.mjs` | 称量模型：七层的名字、原话、标称和实际分量；读数从这里算 |
| `tag.mjs` | 木牌绕绳子转动的几何；生成脚本和页面共用同一份代码 |
| `live.js` | 页面里的动效：弹簧、交错、木牌翻面、指针、读数、减少动态效果 |
| `tools/subset.py`、`fonts/` | 霞鹜文楷子集（只留用到的 178 个字）和它的许可证 |

## 物件和数字

从上到下七层，每层厚 6 毫米，直径 30 厘米。标称分量是领导说的，实际分量是台秤称出来的（克）：

| 层 | 名字 | 木牌背面 | 标称 | 实际 |
|---|---|---|---:|---:|
| 1 | 愿景（芝麻层） | 格局要打开 | 120 | 2 |
| 2 | 升职 | 下一批就考虑你 | 220 | 0 |
| 3 | 加薪 | 等明年效益好了 | 240 | 0 |
| 4 | 年终奖 | 看全年考核 | 160 | 8 |
| 5 | 评优 | 今年名额给你留着 | 110 | 0 |
| 6 | 培训机会 | 有合适的就让你去 | 100 | 5 |
| 7 | 饼底：表扬 | 这次干得不错 | 50 | 50 |
| | 合计 | | 1000 | 65 |

愿景那 2 克就是面上那层芝麻。只有表扬是实打实的，它的木牌背面盖着全图唯一的朱砂红：一枚“已兑现”小印章。

## 读数

卡片右下角的读数是秤上的东西：`标称总重 X 克 · 实际总重 Y 克 · 兑现率 Y/X`，“实际总重”就是指针读数。

- 合拢：整张饼在秤上，`标称总重 1000 克 · 实际总重 65 克 · 兑现率 6.5%`，指针只走到 65 克（表盘一圈 1000 克）。
- 每抬起一层，这一层离开饼堆的那一刻，它的标称和实际分量一起从读数里减掉，指针按实际分量回落：880/63、660/63、420/63、260/55、150/55。抬起升职、加薪、评优时指针一动不动。
- 分开：饼底那层表扬留在盘里，作为爆炸图的底座不动，秤上只剩它：`标称总重 50 克 · 实际总重 50 克 · 兑现率 100%`，正好对上“已兑现”的印章。整张饼的总账（1000 克、65 克、6.5%）写在卡片下面的称量单和说明里。

## 动效

| 动作 | 参数 |
|---|---|
| 触发 | 鼠标或触控笔移进卡片就分开，移出就合上；触屏点按切换；键盘：空格或回车切换，↑ 分开，↓ 或 Esc 合上 |
| 每层抬起 | 弹簧，刚度 36、阻尼 12.6（临界阻尼，不过冲，落回时不会压进下一层），每层 4 个子步；第 1 层抬 228 毫米，往下每层少 38 毫米，饼底不动 |
| 依次 | 分开时从上往下，每层晚 0.28 秒；合上时倒过来，最后抬起的最先落回。中途反悔只重排还没出发的层，已经出发的立刻往回走（和 kit 审计重放的规则一致） |
| 木牌翻面 | 和它那层同时开始，绕绳子转 180°，弹簧刚度 22、阻尼 9.4；牌面明暗随朝向连续变化，接近侧对时文字淡出，不会突然消失；饼底那块在第 7 拍翻 |
| 指针 | 弹簧刚度 70、阻尼 7.5，略欠阻尼，像弹簧秤那样晃一下再停；一层离饼堆超过 0.3 毫米就不再压秤 |
| 读数 | 和指针来自同一时刻的同一份状态，层离开或落回时更新 |
| 减少动态效果 | 只显示分开后的静态画面：木牌全翻好、指针停在 50 克，不响应悬停和点按；运行中切换系统设置会跟着变 |
| 滚出视口 | 停止动画（IntersectionObserver），回来接着走 |

## 尺寸、镜头和颜色

世界单位是毫米，方位角 60°，仰角 30°，viewBox `600 × 586`，0.908 px/mm。台秤底座 560 × 224 × 40 毫米，四只脚；表盘鼓直径 160 毫米，表面直径 134 毫米，100 格（每格 10 克），每 100 克一根长刻度，零点加粗。木牌 34 × 68 × 3 毫米。

| 色名 | 值 | 用在 |
|---|---|---|
| 竹纸 | `#ECEAE1` | 页面底色 |
| 素笺 | `#F8F7F2` | 卡片、表面、铭牌、印章上的字 |
| 松烟墨 | `#24231F` | 线条、文字、指针 |
| 古铜金 | `#C9A86A` | 大饼的四档明暗：`#E2CB98`（顶面）、`#D6BB83`、`#C9A86A`、`#B7955A` |
| 函套青 | `#1F3A4D` | 高脚圆盘和台秤，同一色系由浅到深：`#5D798D` … `#1F3A4D` |
| 朱砂 | `#B5382A` | 只用在“表扬”木牌背面的“已兑现”印章 |

木牌和竹签用素笺一路的浅木色。没有发光，只有底座下面一层柔和的投影。所有文字是中文，字体栈 `"LXGW WenKai","Dabing WenKai","KaiTi","STKaiti",serif`：先用 CDN 的霞鹜文楷；取不到时用内嵌的子集 “Dabing WenKai”（来自 `lxgw-wenkai-webfont@1.7.0` 的 Regular，只做了子集化，SIL OFL 1.1，许可证见 `fonts/OFL.txt`）；再退到楷体。

## 自查

- `node build.mjs --audit`：audit passed。间隙（静止、分开、弹簧重放的每一帧，含每个交错边界前后 8 毫秒的反悔）、绳子两端是否挂在实物上、支撑、深度顺序（1521 个状态）、替身形状、拥挤全部为 0。七层饼之间的深度对在光线求交里跳过：它们同轴同半径、只会直上直下、间隙不会为负，上层永远盖住下层，键值本身就保证这个顺序。输出在 `screenshots/checks/audit.txt`。
- 技能的 `scripts/lines.mjs`：合拢和分开两种姿态都是 `line ends: 0 of 378 ends on 49 lines float`。
- 技能的 `scripts/capture.mjs`、`scripts/drive.mjs`：桌面、手机 390 宽、减少动态效果、分开和合上的连拍，以及每处接缝（七层饼的层缝、饼和盘、高脚盘和秤盘、立柱、表盘鼓、表圈内壁、调零钮、铭牌、水平泡、去皮钮）和每块木牌正反面的 4–10 倍特写，每张都看过。控制台无报错，页面不横向滚动。减少动态效果时的画面和 `open.png` 相同。

## 重建

```sh
node build.mjs            # 写 dabing.html 和 dabing.svg（约 6 分钟，大部分时间在解深度顺序）
node build.mjs --quick    # 草稿：不解深度顺序
node build.mjs --audit    # 同时跑审计
```

改了文字以后重做字体子集：`node build.mjs --chars`，再 `python3 tools/subset.py --package <解开的 lxgw-wenkai-webfont 包目录>`（需要 fontTools 和 brotli）。截图脚本需要 Chrome 或 Chromium：设 `CHROME_PATH`，或者 `npx playwright install chromium`。

```sh
CHROME_PATH=/path/to/chromium node ../../.claude/skills/anatomy/scripts/capture.mjs dabing.html --out shots/closed.png
CHROME_PATH=/path/to/chromium node ../../.claude/skills/anatomy/scripts/lines.mjs dabing.html --out shots/lines.png
```
